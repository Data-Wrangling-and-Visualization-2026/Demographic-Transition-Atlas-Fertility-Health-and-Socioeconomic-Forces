    What The Atlas Shows

    Country-level comparisons for fertility and related indicators such as health spending, urbanization, education, and labor participation.

    Why This Matters

    Demographic change shapes labor markets, healthcare systems, education planning, and long-term policy decisions across regions.

    How To Read Results

    Map color shows relative value for the selected year. Country charts add historical context so you can read both the snapshot and the trend.

    Data And Endpoints

    Data is served through: /countries, /indicators, /timeseries, /events, /map, /db/stats. Keep frontend and backend running locally for live interaction.
